# File Organizer

[English](#english) | [简体中文](#中文)

---

## English

An intelligent file organization tool that automatically sorts files by type and keeps your folders tidy.

### ✨ Features

- 📁 **Auto Organization** - Automatically sort files by type
- 🏷️ **Smart Categorization** - Intelligent file type recognition
- 🔍 **Dry Run Mode** - Preview changes before applying
- 📊 **Statistics** - View organization results
- ⚙️ **Custom Rules** - Define your own organization rules
- 🔄 **Batch Processing** - Organize multiple folders at once
- 📝 **Detailed Logs** - Track all file movements

### 🚀 Quick Start

```bash
cd 11_FileOrganizer
python file_organizer.py
```

### 📂 File Categories

- 📷 **Images**: jpg, png, gif, svg, webp
- 📄 **Documents**: pdf, doc, docx, txt, md
- 📊 **Spreadsheets**: xls, xlsx, csv
- 📽️ **Videos**: mp4, avi, mkv, mov
- 🎵 **Audio**: mp3, wav, flac, aac
- 📦 **Archives**: zip, rar, 7z, tar
- 💻 **Code**: py, js, java, cpp, html
- 🔧 **Executables**: exe, msi, dmg

### 🛠️ Tech Stack

- Python 3.x
- pathlib
- shutil

# 开发效率仪表板 (Dev Dashboard)

## 🎯 项目简介
一个强大的开发效率追踪和分析工具，帮助开发者了解自己的工作模式，提升开发效率。

## ✨ 核心功能

### 📊 数据追踪
- ⏱️ **编码时间统计** - 记录每天的编码时长
- 📝 **代码提交分析** - Git 提交历史分析
- 🎯 **任务完成追踪** - 待办事项和完成情况
- 🔥 **连续工作天数** - 保持编码习惯
- 📈 **效率趋势分析** - 长期效率变化

### 📉 可视化展示
- 📊 **时间分布图** - 每日/每周/每月工作时间
- 🔥 **热力图** - GitHub 风格的提交热力图
- 📈 **趋势图表** - 效率变化趋势
- 🎨 **语言分布** - 使用的编程语言统计
- 📁 **项目统计** - 各项目工作时间分布

### 🎯 目标管理
- ✅ **每日目标** - 设定和追踪每日目标
- 🏆 **成就系统** - 解锁各种成就徽章
- 📅 **周/月计划** - 长期目标规划
- 💪 **习惯养成** - 培养良好的编码习惯

### 📱 实时监控
- 🔔 **实时提醒** - 工作时间提醒
- 📊 **实时统计** - 当前工作状态
- 🎮 **番茄钟** - 番茄工作法集成
- 💡 **效率建议** - AI 驱动的效率提升建议

## 🛠️ 技术栈

### 后端
- Python 3.x
- Flask / FastAPI
- SQLite / PostgreSQL
- GitPython (Git 分析)

### 前端
- HTML5 / CSS3
- JavaScript (ES6+)
- Chart.js (图表)
- D3.js (高级可视化)

### 数据分析
- Pandas
- NumPy
- Matplotlib / Seaborn

## 📖 使用方法

### 快速开始
```bash
# 安装依赖
pip install -r requirements.txt

# 初始化数据库
python init_db.py

# 启动服务
python app.py
```

### 访问仪表板
打开浏览器访问: http://localhost:5000

## 🚀 功能特色

1. **自动追踪** - 无需手动记录，自动分析 Git 历史
2. **美观直观** - 现代化的界面设计
3. **深度分析** - 多维度的数据分析
4. **隐私保护** - 所有数据本地存储
5. **轻量高效** - 资源占用少，运行流畅

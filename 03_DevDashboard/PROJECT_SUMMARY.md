### Git 分析功能
- 提交数量统计

- 提交时间分布（按小时）
- 工作日分布（周一到周日）
- 编程语言使用统计
- 连续提交天数追踪

### 工作时间追踪
- 开始/结束工作会话
- 按项目分类统计

### 可视化展示
- 统计卡片（4个核心指标）
- 图表区域（预留 Chart.js 集成）
- 提交热力图（GitHub 风格）
- 目标进度条
- 活动时间线

## 🚀 使用方法

### 命令行模式
```bash
# 分析 Git 仓库
python tracker.py analyze --repo . --days 30

# 开始工作
python tracker.py start --project my-project

# 结束工作
python tracker.py end

# 查看统计
python tracker.py stats
```

### Web 仪表板
直接在浏览器中打开 `dashboard.html`

## English

A high-quality AI translation tool with context awareness and professional terminology support.

### ✨ Features

- 🌍 **Multi-language Translation** - Support multiple language pairs
- 📝 **Context-aware Translation** - Accurate translation with context
- 🎓 **Professional Translation** - Domain-specific terminology
- ✨ **Text Polishing** - Optimize text expression
- 📊 **Text Summarization** - Extract key information
- 🔄 **Batch Translation** - Translate multiple files
- 📖 **Translation Memory** - Reuse previous translations

### 🚀 Quick Start

```bash
cd AITranslator
python ai_translator.py --text "Hello World" --target zh
```

### 💡 Use Cases

- Document translation
- Language learning
- Technical documentation translation
- Text polishing
- Content localization

### 🛠️ Tech Stack

- Python 3.x
- Ollama (Local AI)
- Multi-language support

## 中文

一个高质量的AI翻译工具，具有上下文感知和专业术语支持。

### ✨ 功能特性

- 🌍 **多语言翻译** - 支持多种语言互译
- 📝 **上下文翻译** - 带上下文的精准翻译
- 🎓 **专业翻译** - 专业领域术语翻译
- ✨ **文本润色** - 优化文本表达
- 📊 **文本总结** - 提取关键信息
- 🔄 **批量翻译** - 翻译多个文件
- 📖 **翻译记忆** - 重用之前的翻译

### 🚀 快速开始

```bash
cd AITranslator
python ai_translator.py --text "你好世界" --target en
```

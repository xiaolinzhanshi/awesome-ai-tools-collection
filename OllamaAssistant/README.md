# 🤖 Ollama AI对话助手

利用本地AI模型提供智能对话服务

## ✨ 功能特性

- 💬 **智能对话** - 与AI进行自然对话
- 🔄 **流式响应** - 实时显示AI回复
- 💾 **历史保存** - 保存对话记录
- 🎯 **多模型** - 支持切换不同AI模型
- 📝 **对话导出** - 导出为JSON格式

## 🚀 使用方法

```bash
python ollama_assistant.py
```

## 📋 支持的模型

- llama3.2:latest
- gemma3:4b
- qwen3-vl:latest

## 💡 使用场景

- 日常问答
- 学习辅导
- 创意写作
- 技术咨询

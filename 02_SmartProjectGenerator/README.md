# 智能项目生成器 (Smart Project Generator)

## 🎯 项目简介
一个强大的项目脚手架工具，能够根据用户需求快速生成完整的项目结构和代码框架。

## ✨ 核心功能
- 🚀 **快速生成** - 一键生成完整项目结构
- 🎨 **模板丰富** - 支持多种项目类型
- ⚙️ **高度可配置** - 自定义项目参数
- 📦 **依赖管理** - 自动生成依赖配置文件
- 🔧 **开发工具** - 集成常用开发工具配置

## 📋 支持的项目类型

### Web 应用
- ✅ React + TypeScript
- ✅ Vue 3 + Vite
- ✅ Next.js
- ✅ Express.js API
- ✅ Flask Web App
- ✅ Django Project

### 桌面应用
- ✅ Electron App
- ✅ PyQt5 Application
- ✅ Tkinter GUI

### 数据科学
- ✅ Jupyter Notebook Project
- ✅ Machine Learning Pipeline
- ✅ Data Analysis Template

### 工具和库
- ✅ Python Package
- ✅ Node.js Module
- ✅ Chrome Extension

## 🛠️ 技术栈
- Python 3.x
- Jinja2 模板引擎
- Click 命令行框架
- Rich 终端美化

## 📖 使用方法

### 命令行模式
```bash
python generator.py create --type web-react --name my-app
```

### 交互式模式
```bash
python generator.py interactive
```

### Web 界面
```bash
python generator.py serve
```

## 🚀 快速开始

1. 安装依赖
```bash
pip install -r requirements.txt
```

2. 运行生成器
```bash
python generator.py
```

3. 选择项目类型并配置参数

4. 生成完成！

## English

A comprehensive personal finance management tool to help you track income/expenses, manage budgets, and generate financial reports.

### ✨ Features

- 💰 **Income & Expense Tracking** - Record all your financial transactions
- 📊 **Budget Management** - Set and track monthly budgets by category
- 💳 **Account Management** - Manage multiple accounts (bank, cash, credit card)
- 📈 **Financial Reports** - Generate detailed financial analysis and charts
- 🏷️ **Category Management** - Organize transactions by custom categories
- 📅 **Date Range Filtering** - View transactions for any time period
- 💡 **Smart Insights** - Get spending insights and recommendations

### 🚀 Quick Start

#### Installation

```bash
# Clone the repository
cd 07_PersonalFinanceManager

# Install dependencies
pip install flask

# Initialize database
python app.py
```

#### Usage

```bash
# Start the application
python app.py

# Open browser and visit
http://localhost:5000
```

### 📊 Main Features

#### 1. Transaction Management
- Add income/expense records
- Edit and delete transactions
- Search and filter by date/category
- Add notes and descriptions

#### 2. Budget Planning
- Set monthly budgets for each category
- Track budget usage in real-time
- Get alerts when approaching budget limits
- View budget vs actual spending

#### 3. Account Management
- Manage multiple accounts
- Track account balances
- Transfer between accounts
- View account history

#### 4. Reports & Analytics
- Monthly/yearly financial summaries
- Category-wise spending analysis
- Income vs expense trends
- Visual charts and graphs

### 🛠️ Tech Stack

- **Backend**: Flask (Python)
- **Database**: SQLite
- **Frontend**: HTML/CSS/JavaScript
- **Charts**: Chart.js (planned)

## 中文

一个综合的个人财务管理工具，帮助您追踪收支、管理预算并生成财务报告。

### ✨ 功能特性

- 💰 **收支追踪** - 记录所有财务交易
- 📊 **预算管理** - 按类别设置和追踪月度预算
- 💳 **账户管理** - 管理多个账户（银行、现金、信用卡）
- 📈 **财务报告** - 生成详细的财务分析和图表
- 🏷️ **分类管理** - 按自定义类别组织交易
- 📅 **日期范围筛选** - 查看任意时间段的交易
- 💡 **智能洞察** - 获取消费洞察和建议

### 🚀 快速开始

#### 安装

```bash
# 克隆仓库
cd 07_PersonalFinanceManager

# 安装依赖
pip install flask

# 初始化数据库
python app.py
```

#### 使用

```bash
# 启动应用
python app.py

# 打开浏览器访问
http://localhost:5000
```

### 📊 主要功能

#### 1. 交易管理
- 添加收入/支出记录
- 编辑和删除交易
- 按日期/类别搜索和筛选
- 添加备注和描述

#### 2. 预算规划
- 为每个类别设置月度预算
- 实时追踪预算使用情况
- 接近预算限制时获取提醒
- 查看预算与实际支出对比

#### 3. 账户管理
- 管理多个账户
- 追踪账户余额
- 账户间转账
- 查看账户历史

#### 4. 报告与分析
- 月度/年度财务摘要
- 按类别的支出分析
- 收入与支出趋势
- 可视化图表

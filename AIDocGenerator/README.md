## English

Automatically generate project documentation, README, API docs, and more using AI.

### ✨ Features

- 📝 **README Generation** - Auto-generate professional README
- 📚 **API Documentation** - Generate detailed API docs
- 📖 **User Guides** - Create user manuals
- 📋 **Changelog** - Generate CHANGELOG
- 🤝 **Contributing Guide** - Generate CONTRIBUTING
- 🔍 **Project Analysis** - Analyze project to generate docs
- 🌍 **Multi-language** - Support multiple languages

### 🚀 Quick Start

```bash
cd AIDocGenerator
python ai_doc_generator.py --project /path/to/project
```

### 💡 Use Cases

- Project documentation writing
- API documentation generation
- Open source project maintenance
- Technical documentation creation
- Documentation updates

### 🛠️ Tech Stack

- Python 3.x
- Ollama (Local AI)
- Markdown generation

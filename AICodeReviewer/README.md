# AI Code Reviewer

[English](#english) | [简体中文](#中文)

---

## English

An AI-powered code review tool using local AI models for comprehensive code analysis and optimization.

### ✨ Features

- 🔍 **Code Review** - Comprehensive code quality analysis
- ⚡ **Code Optimization** - Provide optimization suggestions
- 📖 **Code Explanation** - Detailed code logic explanation
- 🐛 **Bug Detection** - Find potential issues
- 🧪 **Test Generation** - Auto-generate unit tests
- 📊 **Complexity Analysis** - Calculate code complexity
- 🎯 **Best Practices** - Suggest coding best practices

### 🚀 Quick Start

```bash
cd AICodeReviewer
python ai_code_reviewer.py your_code.py
```

### 💡 Use Cases

- Code review before commits
- Learning code patterns
- Bug fixing assistance
- Test case generation
- Code refactoring guidance

### 🛠️ Tech Stack

- Python 3.x
- Ollama (Local AI)
- AST parsing

# Smart Study Assistant 智能学习助手

[English](README.md) | [中文](README_CN.md)

## Introduction 介绍

Smart Study Assistant is a powerful learning management tool that helps students improve learning efficiency using the Pomodoro Technique and other scientific methods.

智能学习助手是一款强大的学习管理工具，帮助学生使用番茄工作法和其他科学方法提高学习效率。

## Features 功能特性

- **Pomodoro Timer** - 25-minute focus + 5-minute break
- **Note System** - Rich text note taking
- **Task Management** - Daily task planning
- **Statistics Tracking** - Learning time visualization
- **Responsive Design** - Works on all devices

- **番茄工作法** - 25分钟专注 + 5分钟休息
- **笔记系统** - 富文本笔记记录
- **任务管理** - 每日任务规划
- **统计追踪** - 学习时间可视化
- **响应式设计** - 适配所有设备

## Installation 安装

```bash
pip install -r requirements.txt
python app.py
```

Visit http://localhost:5000

访问 http://localhost:5000

## Usage 使用方法

1. Start a study session with your subject
2. Use Pomodoro timer for focused learning
3. Take notes during study
4. Track your progress

1. 选择科目开始学习会话
2. 使用番茄钟进行专注学习
3. 学习过程中记录笔记
4. 追踪学习进度

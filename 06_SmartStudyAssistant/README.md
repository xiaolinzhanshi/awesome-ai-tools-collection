# 🎓 智能学习助手 (Smart Study Assistant)

## 项目简介
一个强大的学习管理工具，帮助学生提高学习效率，管理学习计划，追踪学习进度。

## ✨ 核心功能

### 📚 学习管理
- **番茄钟学习法** - 25分钟专注 + 5分钟休息
- **学习计划** - 制定每日/每周学习计划
- **进度追踪** - 可视化学习进度
- **目标设定** - 设定学习目标并追踪完成情况

### 📝 笔记系统
- **Markdown笔记** - 支持Markdown格式
- **标签分类** - 按科目、主题分类
- **快速搜索** - 全文搜索笔记内容
- **笔记导出** - 导出为PDF、HTML

### 📊 数据分析
- **学习时长统计** - 每日/每周/每月学习时间
- **科目分布** - 各科目学习时间占比
- **效率分析** - 学习效率趋势图
- **成就系统** - 解锁学习成就

### 🎯 智能提醒
- **学习提醒** - 定时提醒学习
- **休息提醒** - 避免过度疲劳
- **复习提醒** - 艾宾浩斯遗忘曲线复习
- **任务提醒** - 作业和考试提醒

## 🛠️ 技术栈

### 后端
- Python 3.x
- Flask (Web框架)
- SQLite (数据库)
- APScheduler (定时任务)

### 前端
- HTML5 / CSS3
- JavaScript (ES6+)
- Chart.js (数据可视化)
- Marked.js (Markdown渲染)

## 📖 使用方法

### 安装依赖
```bash
pip install -r requirements.txt
```

### 启动应用
```bash
python app.py
```

### 访问应用
打开浏览器访问: http://localhost:5000

## 🎨 界面特色

- 🌈 **现代化设计** - 清新的配色方案
- 📱 **响应式布局** - 支持手机、平板、电脑
- 🌙 **暗色模式** - 护眼的夜间模式
- ⚡ **流畅动画** - 优雅的过渡效果

## 🚀 快速开始

1. 创建学习计划
2. 开始番茄钟学习
3. 记录学习笔记
4. 查看学习统计

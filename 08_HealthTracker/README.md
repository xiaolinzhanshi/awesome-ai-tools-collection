# Health Tracker

[English](#english) | [简体中文](#中文)

---

## English

A comprehensive health and lifestyle tracking application to help you monitor exercise, diet, sleep, and water intake.

### ✨ Features

- 💪 **Exercise Tracking** - Record daily workouts and activities
- 🍎 **Diet Monitoring** - Track meals and calorie intake
- 😴 **Sleep Analysis** - Monitor sleep quality and duration
- 💧 **Water Reminder** - Track daily water consumption
- 📊 **Health Reports** - Generate comprehensive health analytics
- 🎯 **Goal Setting** - Set and track health goals
- 📈 **Progress Visualization** - View trends with charts and graphs

### 🚀 Quick Start

```bash
# Navigate to project directory
cd 08_HealthTracker

# Install dependencies
pip install flask

# Run the application
python health_app.py

# Visit in browser
http://localhost:5002
```

### 📊 Main Features

#### Exercise Tracking
- Log different types of exercises
- Track duration and intensity
- Calculate calories burned
- View exercise history

#### Diet Management
- Record meals and snacks
- Track calorie intake
- Monitor nutritional balance
- Set dietary goals

#### Sleep Monitoring
- Log sleep duration
- Track sleep quality
- Analyze sleep patterns
- Get sleep recommendations

#### Water Intake
- Set daily water goals
- Log water consumption
- Get hydration reminders
- Track hydration trends

### 🛠️ Tech Stack

- **Backend**: Python + Flask
- **Database**: SQLite
- **Frontend**: HTML/CSS/JavaScript
- **Visualization**: Chart.js

### 📁 Project Structure

```
08_HealthTracker/
├── health_app.py       # Main application
├── templates/          # HTML templates
├── static/            # CSS/JS files
├── health.db          # SQLite database
└── README.md          # Documentation
```

## 中文

一个综合的健康和生活方式追踪应用，帮助您监控运动、饮食、睡眠和饮水。

### ✨ 功能特性

- 💪 **运动追踪** - 记录每日锻炼和活动
- 🍎 **饮食监控** - 追踪餐食和卡路里摄入
- 😴 **睡眠分析** - 监控睡眠质量和时长
- 💧 **喝水提醒** - 追踪每日饮水量
- 📊 **健康报告** - 生成综合健康分析
- 🎯 **目标设定** - 设置和追踪健康目标
- 📈 **进度可视化** - 通过图表查看趋势

### 🚀 快速开始

```bash
# 进入项目目录
cd 08_HealthTracker

# 安装依赖
pip install flask

# 运行应用
python health_app.py

# 在浏览器中访问
http://localhost:5002
```

# Bookmark Manager

[English](#english) | [简体中文](#中文)

---

## English

A powerful bookmark management tool to organize and search your web bookmarks efficiently.

### ✨ Features

- 🔖 **Bookmark Management** - Add, edit, delete bookmarks
- 🏷️ **Tag System** - Organize with tags
- 🔍 **Smart Search** - Quick search by title, URL, or tags
- 📊 **Statistics** - View bookmark statistics
- 📁 **Folders** - Organize in folders
- 🌐 **Import/Export** - Browser bookmark import
- ⭐ **Favorites** - Mark important bookmarks

### 🚀 Quick Start

```bash
cd 12_BookmarkManager
python bookmark_manager.py
```

### 🛠️ Tech Stack

- Python 3.x
- JSON storage
- urllib

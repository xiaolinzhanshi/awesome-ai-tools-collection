# Todo Master

[English](#english) | [简体中文](#中文)

---

## English

A powerful task management tool with projects, priorities, tags, and more.

### ✨ Features

- ✅ **Task Management** - Add, complete, delete tasks
- 📁 **Projects** - Organize tasks by project
- 🎯 **Priorities** - Set task priorities (High/Medium/Low)
- 🏷️ **Tags** - Flexible tagging system
- 📅 **Due Dates** - Set and track deadlines
- 📊 **Statistics** - View productivity stats
- 🔍 **Smart Filters** - Filter by project, priority, tags

### 🚀 Quick Start

```bash
cd 13_TodoMaster
python todo_master.py
```

### 🛠️ Tech Stack

- Python 3.x
- JSON storage
- datetime
